# AURA // Immersive Digital Art & Vector System

A standalone interactive digital art experience and vector design system inspired by **Magnific AI's vector library aesthetic** (`magnific.com/vectors/figma-design-system`).

> **Safety Notice:** This project is completely isolated in `D:\Antigravity Project's File\Digital Art Immersive Experience` and touches no files in any other open workspace or repository.

---

## Highlights & Features

### 1. Five Generative Vector Art Exhibition Modes
* **01. Vector Morph (`flowfield`)**: Multi-octave trigonometric flow field with thousands of chromatic vector particle ribbons responding dynamically to velocity and cursor vortex physics.
* **02. Neon Silk (`aurora`)**: Additive fluid ribbon wave simulating iridescent digital silk undulations.
* **03. Matrix 3D (`lattice`)**: Isometric depth mesh with interconnected glowing spatial nodes that displace dynamically with mouse proximity.
* **04. Singularity (`supernova`)**: Quantum particle swarm exploding and contracting into gravitational orbital wells.
* **05. Topography (`topography`)**: Cybernetic elevation contour map with interactive height ripple depressions.

### 2. Built-in Procedural Audio Soundscape (Web Audio API)
* Continuous polyphonic ambient synthesizer drone (C minor pentatonic harmony).
* Real-time cursor audio modulation:
  * **Y-axis:** Modulates low-pass resonant filter cutoff frequency (200 Hz to 3400 Hz).
  * **X-axis:** Modulates real-time stereo panning.
  * **Clicks:** Generates dynamic harmonic chime overtones.
* Zero external audio files required — synthesized entirely in real-time.

### 3. Interactive Floating Dock Controls
* **Turbulence:** Adjust chaotic divergence of the vector fields.
* **Vector Density:** Scale particle rendering from 200 to 2500 active nodes.
* **Kinetic Speed:** Control time step velocity.
* **Chromatic Palettes:** Switch between *Cyber Neon*, *Spectral Aurora*, *Solar Flare*, and *Liquid Silver*.
* **Vortex / Gravity Well:** Toggle cursor force field mode between rotational swirl and gravitational attraction.
* **Vector Snapshot:** One-click instant high-resolution PNG export of the current canvas frame.

### 4. Figma Vector Design System Drawer
* Accessible via the top navigation `DESIGN SYSTEM` pill button.
* Outlines color tokens, glass elevation surfaces, typographic hierarchy (`Space Grotesk`, `Plus Jakarta Sans`, `JetBrains Mono`), and atomic component patterns.
* Includes machine-readable W3C Design Tokens spec in `figma-tokens.json`.

```bash

```
